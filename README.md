# SDAIA Agentic AI Labs

## About the Project
This repository contains my practical implementation and learning exercises from the SDAIA Agentic AI labs, using Google Colab.

## Objectives
- Learn the fundamentals of Agentic AI.
- Practice working with AI agents and language models.
- Explore model configuration, API integration, and response handling.
- Document practical experiments and learning outcomes.

## Tools and Technologies
- Python
- Google Colab
- Agentic AI
- OpenRouter API

## Project Structure
The repository will contain notebooks, code, and documentation related to the completed labs.

## How to Use
1. Open a notebook in the repository.
2. Click **Open in Colab** if the notebook supports it.
3. Follow the instructions in the notebook.
4. Configure your API key securely when required.

## Security
Never upload API keys, passwords, or other secrets to this repository.
